# Как попасть в список  «Awesome MAX» — открытый, курируемый и независимый список проектов экосистемы мессенджера MAX. Любой живой проект ниши может быть включён — включая прямых конкурентов уже перечисленных инструментов.  ## Принципы списка  - **Честность.** Описание состоит из проверяемых фактов: что делает проект, какие у него возможности. Без превосходных степеней («лучший», «самый удобный») и маркетинга. - **Полнота.** Список собирает всю нишу, а не только избранное. Конкурирующие между собой фреймворки, конструкторы и сервисы сосуществуют здесь на общих основаниях. - **Порядок по зрелости.** Внутри секции сначала идут более зрелые проекты — по полноте документации, стабильности API и признакам жизни, а не по личным предпочтениям.  ## Критерии включения  Проект попадает в список, если:  1. Относится к экосистеме MAX: Bot API, User API, мини-приложения (WebApp), мосты, интеграции, материалы для разработчиков. 2. Публично доступен: открытый репозиторий или публичный сервис. 3. Живой: коммиты или релизы за последние ~12 месяцев, либо завершённость (стабильный релиз, полная документация) при отсутствии активности. 4. Имеет README с описанием установки и использования (на русском или английском). 5. Не наносит вреда: не крадёт токены, не маскирует вредоносный код под библиотеку.  ## Как оформить PR  - Один проект — один PR. - Формат записи:    ```markdown   - [Название](https://ссылка) (`команда установки`) — что делает, 1–2 конкретных факта.   ```  - Язык — русский. Названия пакетов и команды установки — в бэктиках. - Сначала проверьте, что ссылки работают, а пакет существует в репозитории пакетов (npm/PyPI/NuGet и т.д.). - Новую запись добавляйте внутрь секции с учётом порядка по зрелости: зрелые проекты — выше.  ## Правки и удаление  - Мейнтейнер проекта может предложить правку описания своего проекта — такие PR приоритетны. - Мёртвые проекты (архив репозитория, битая ссылка, ~год без активности и признаков завершённости) удаляются. Если проект снова ожил — вернём обратным PR. - Если ссылка «протухла» (сайт переехал, пакет переименован) — правьте, не удаляя запись.  ## Конфликт интересов  ## Лицензия  Материалы списка — [CC0-1.0](LICENSE).
