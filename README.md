# Awesome MAX [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)  > Курируемый список SDK, фреймворков, библиотек, инструментов и материалов для разработки ботов и мини-приложений в мессенджере [MAX](https://max.ru).  MAX — российский мессенджер с открытым Bot API. Экосистема молодая и быстро растёт: этот список собирает всё полезное в одном месте — от официальных SDK до комьюнити-фреймворков, мостов, юзерботов и MCP-серверов.  **Принципы списка:** честность и полнота. Сюда попадают все живые проекты ниши, включая конкурирующие между собой. Порядок внутри секций — по зрелости и полноте документации, а не по симпатиям. Нашли неточность или знаете проект, которого нет, — [смотрите правила](CONTRIBUTING.md) и присылайте PR.  > ⚖️ **Важно про доступ к платформе:** создание и публикация ботов и мини-приложений доступны верифицированным организациям — юрлицам, ИП и самозанятым, являющимся резидентами РФ (физлица и нерезиденты верификацию не проходят). Верификация проходит в бизнес-кабинете [business.max.ru](https://business.max.ru). Актуальные условия — в [Правилах платформы](https://dev.max.ru/docs/legal/rules) и разделе [Статьи и материалы](#статьи-и-материалы).  ## Содержание  - [Официальные ресурсы](#официальные-ресурсы) - [Официальные SDK и инструменты](#официальные-sdk-и-инструменты) - [Фреймворки и библиотеки](#фреймворки-и-библиотеки)   - [JavaScript / TypeScript](#javascript--typescript)   - [Python](#python)   - [Go](#go)   - [PHP](#php)   - [Java](#java)   - [.NET](#net)   - [Rust](#rust)   - [1С](#1с) - [Мини-приложения (WebApp)](#мини-приложения-webapp) - [Мосты MAX ↔ Telegram](#мосты-max--telegram) - [User API и юзерботы](#user-api-и-юзерботы) - [MCP и ИИ-интеграции](#mcp-и-ии-интеграции) - [Интеграции и автоматизация](#интеграции-и-автоматизация) - [Конструкторы и no-code](#конструкторы-и-no-code) - [Примеры и шаблоны](#примеры-и-шаблоны) - [Статьи и материалы](#статьи-и-материалы) - [Сообщества](#сообщества) - [Как попасть в список](#как-попасть-в-список)  ---  ## Официальные ресурсы  - [dev.max.ru](https://dev.max.ru) — портал разработчика MAX: документация Bot API и мини-приложений, MAX UI, история изменений. - [Документация](https://dev.max.ru/docs) — обзор платформы: чат-боты, мини-приложения, подключение бизнеса. - [Bot API Reference](https://dev.max.ru/docs-api) — методы API, авторизация по заголовку `Authorization`, коды ошибок. Актуальный домен API — `platform-api2.max.ru` (передача токена query-параметрами больше не поддерживается). - [Документация по мини-приложениям](https://dev.max.ru/docs/webapps) — устройство WebApp, bridge, валидация initData. - [business.max.ru](https://business.max.ru) — бизнес-кабинет: верификация организации, создание бота, модерация. Токен бота выдаётся в разделе «Чат-боты → Настройки» или через бота/мини-приложение «MAX для бизнеса» (команда «Получить токен»). - [github.com/max-messenger](https://github.com/max-messenger) — официальная организация на GitHub: SDK, демо-боты, OpenAPI-схема, UI-кит. - [Правила платформы](https://dev.max.ru/docs/legal/rules) и [требования к ботам](https://dev.max.ru/docs/legal/requirements) — обязательное чтение перед публикацией.  ## Официальные SDK и инструменты  - [max-bot-api-client-ts](https://github.com/max-messenger/max-bot-api-client-ts) — официальный JS/TS SDK (`npm i @maxhub/max-bot-api`): команды, hears-хэндлеры, сессии и пошаговые сценарии из коробки, long polling и webhook. - [max-bot-api-client-go](https://github.com/max-messenger/max-bot-api-client-go) — официальный клиент для Go: обновления через webhook-подписки, билдеры сообщений и клавиатур. - [maxbot](https://pkg.go.dev/github.com/max-messenger/maxbot) — официальный Go-фреймворк поверх клиента: роутинг команд, контексты, middleware. - [max-botapi-python](https://github.com/max-messenger/max-botapi-python) — Python-библиотека в организации MAX (fork сообщества). - [demo-bot-go](https://github.com/max-messenger/demo-bot-go) — официальный демо-бот: сценарии по всем возможностям Bot API — клавиатуры, вложения, загрузка файлов, администрирование чатов. Живой бот: `max.ru/max_demo_bot`. - [max-bot-example-todolist](https://github.com/max-messenger/max-bot-example-todolist) — официальный пример бота (Go). - [api-schema](https://github.com/max-messenger/api-schema) — официальная OpenAPI-схема Bot API: генерация типизированных клиентов для любого языка. - [max-ui](https://github.com/max-messenger/max-ui) — официальный React UI-кит для мини-приложений по дизайн-системе MAX.  ## Фреймворки и библиотеки  ### JavaScript / TypeScript  - [umbot](https://github.com/max36895/umbot) (`npm i umbot`) — мультиплатформенный фреймворк: пишете логику один раз, дальше работают адаптеры — Алиса, Сбер SmartApp, Маруся, Telegram, VK, **MAX**, Viber из коробки. CLI-генератор проектов, защита от ReDoS, встроенное состояние и кэширование медиа, SemVer. - [maxbot-ts](https://github.com/DementevVV/maxbot-ts) (`npm i @dementevdev/maxbot-ts`) — production-ориентированный фреймворк: polling и webhook с проверкой `X-Max-Bot-Api-Secret` (timing-safe), middleware-пайплайн в стиле Koa/Telegraf, Filter DSL, inline-клавиатуры, resumable-загрузка файлов, метрики обработки апдейтов. - [max-bot-ts](https://github.com/sergey12313/max-bot-ts) (`npm i max-bot-ts`) — `Bot` и `Context` на middleware, long polling и webhook для Node.js без лишних зависимостей, сессии, сцены/FSM, хелперы клавиатур и вложений. - [nestjs-max](https://github.com/xTCry/nestjs-max) + [max-io](https://www.npmjs.com/package/max-io) — интеграция MAX-ботов в NestJS: декораторы `@MaxUpdate` / `@MaxOn` / `@MaxHears`, сессии (включая Redis), i18n. - [maxbot-api-client-ts](https://github.com/green-api/maxbot-api-client-ts) (`npm i @green-api/maxbot-api-client-ts`) — строго типизированный SDK от GREEN-API: полное покрытие Bot API, встроенный rate limiter, long-polling и вебхуки. - [max-bot-menu](https://www.npmjs.com/package/max-bot-menu) — grammY-подобная система меню для MAX Bot API.  ### Python  - [maxo](https://github.com/K1rL3s/maxo) (`pip install maxo`) — асинхронный фреймворк в духе aiogram: роутеры, фильтры, middleware, FSM (в т.ч. Redis), диалоги с HTML-превью и тестами без сети, webhook на aiohttp/FastAPI, строгая типизация (`mypy --strict`), Python 3.12+. - [maxapi](https://github.com/love-apples/maxapi) (`pip install maxapi`) — aiogram-стиль: `Dispatcher`/`Router`, `F`-фильтры, FSM (Memory/Redis), polling и webhook через aiohttp, FastAPI или Litestar, типизированные callback payloads. - [aiomax](https://github.com/dpnspn/aiomax) (`pip install aiomax`) — асинхронный фреймворк в стиле aiogram: роутеры, FSM, middleware, совместимость с PyPy, своё сообщество. - [umaxbot](https://pypi.org/project/umaxbot/) (`pip install umaxbot`) — асинхронный фреймворк со синтаксисом как у aiogram: polling, inline-кнопки, файлы, FSM, роутеры, фильтры. - [maxgram](https://github.com/KayumovRu/maxgram) (`pip install maxgram`) — один из первых клиентов экосистемы (март 2025): минимальный синхронный API для сообщений и inline-кнопок. Разработка в ранней стадии. - [maxbot-api-client-python](https://github.com/green-api/maxbot-api-client-python) (`pip install maxbot-api-client-python`) — SDK от GREEN-API: синхронный и асинхронный режимы, контекстные менеджеры, rate limiter, полное покрытие Bot API.  ### Go  - Официальные [max-bot-api-client-go](https://github.com/max-messenger/max-bot-api-client-go) и фреймворк [maxbot](https://pkg.go.dev/github.com/max-messenger/maxbot) — см. раздел [Официальные SDK и инструменты](#официальные-sdk-и-инструменты). - [maxigo](https://github.com/maxigo-bot/maxigo-bot) + [maxigo-client](https://github.com/maxigo-bot/maxigo-client) — Go-фреймворк (router, middleware, context) и HTTP-клиент для Bot API.  ### PHP  - [max-bot-api-client-php](https://github.com/BushlanovDev/max-bot-api-client-php) — клиент Max Bot API для PHP с примерами в README. - [Max-platform-PHP-SDK](https://github.com/WebTolk/Max-platform-PHP-SDK) — framework-agnostic PHP SDK: PSR-18, типизированные entities, «проверено на реальном API».  ### Java  - Официального Java-клиента в [max-messenger](https://github.com/max-messenger) нет — генерируйте клиент по [OpenAPI-схеме](https://github.com/max-messenger/api-schema) под свою экосистему (Retrofit, OpenFeign и т.п.). - [max-bot-api-java](https://github.com/etsft/max-bot-api-java) — сторонний Java-клиент (`ru.etsft.max:max-bot-api-client`).  ### .NET  - [MaxMessenger.Bot](https://www.nuget.org/packages/MaxMessenger.Bot) (`dotnet add package MaxMessenger.Bot`) — C#-библиотека для .NET 8/9/10: модульные API-клиенты, long polling и webhook-конвейер, retry/backoff и обработка rate limit, XML-документация всех публичных типов. Статус: alpha, активная разработка. - [Max.BotClient](https://github.com/Deskri/Max.BotClient) — неофициальный .NET SDK: multi-target, DI-расширения.  ### Rust  - [rumax](https://github.com/junioraww/rumax) — порт API-клиента на Rust (частичное покрытие) — пока единственная Rust-библиотека экосистемы.  ### 1С  - [max-api-client-1c](https://github.com/green-api/max-api-client-1c) — внешняя обработка для 1С:Предприятие 8.3.10+: отправка сообщений, файлов, работа с группами и журналами через GREEN-API; можно встроить в собственную конфигурацию.  ## Мини-приложения (WebApp)  - [MAX Bridge](https://dev.max.ru/docs/webapps/bridge) — официальная документация bridge API: подключение `max-web-app.js`, обмен сообщениями между мини-приложением и клиентом MAX. - [max-validate-init-data](https://www.npmjs.com/package/max-validate-init-data) — валидация `init_data` мини-приложений на Node.js (двухшаговый HMAC-SHA256). - [family_bot](https://github.com/irosssss/family_bot) — пример production мини-приложения (React + Vite + Express): один код работает и в Telegram, и в MAX.  ## Мосты MAX ↔ Telegram  > ⚠️ Мосты, работающие через личный аккаунт, используют неофициальные протоколы — риски описаны в разделе [User API и юзерботы](#user-api-и-юзерботы).  - [max2tg](https://github.com/Aist/max2tg) — самый популярный мост: двусторонняя пересылка текста, медиа и реплаев между MAX и Telegram, поддержка SOCKS5. - [telegram-max-bridge](https://github.com/620x/telegram-max-bridge) — шлюз Telegram Bot API → MAX Bot API: существующий Telegram-бот работает в MAX без переписывания кода. - [max-resend](https://github.com/timka-123/max-resend) — простой forwarder MAX → Telegram. - [MaxAutopost](https://github.com/buvanenko/MaxAutopost) — кросспостинг Telegram-канал → канал MAX. - [SferumTransferBot](https://github.com/Sharkow1743/SferumTransferBot) — пересылка всех сообщений из Сферума (MAX) в Telegram.  ## User API и юзерботы  > ⚠️ Библиотеки этого раздела работают с пользовательским аккаунтом через неофициальные протоколы. Протокол может измениться без предупреждения, а автоматизация — повлечь ограничения аккаунта. Используйте отдельный аккаунт и на свой риск.  - [PyMax](https://github.com/MaxApiTeam/PyMax) — асинхронный враппер внутреннего API MAX (MAX Manager): авторизация, чаты, сообщения в реальном времени. Самый звёздный проект сегмента. - [pyromax](https://github.com/rast-games/pyromax) — aiogram-подобный фреймворк для юзерботов. - [vkmax](https://github.com/nsdkinx/vkmax) — Python-клиент внутреннего API MAX (OneMe). - [max-user-api](https://github.com/mochensky/max-user-api) — асинхронная Python-библиотека доступа к MAX через WebSocket: авторизация, чаты, сообщения в реальном времени, медиа. По заявлению автора — очень ранняя, сырая стадия. - [max-api-client-python](https://github.com/green-api/max-api-client-python) (`pip install max-api-client-python`) — доступ к API пользовательского аккаунта через сервис GREEN-API: сообщения, группы, журналы, webhook-уведомления; авторизация по SMS или QR-коду, есть бесплатный тариф разработчика. - [max-api-docs](https://github.com/pr0bel1230/max-api-docs) — документация по реверс-инжинирингу протокола MAX.  ## MCP и ИИ-интеграции  - [mcp-max-messenger](https://github.com/woyaxnini/mcp-max-messenger) (`npx @woyax/mcp-max-messenger`) — MCP-сервер на Bot API: 20+ инструментов (сообщения, медиа, участники, админы, события), режимы stdio и HTTP, готовые конфиги для Claude Desktop, Cursor и n8n. Лицензия MIT + Commons Clause (запрет продажи hosted-варианта). - [max-mcp](https://github.com/renosaza/max-mcp) — локальный MCP-сервер на пользовательской сессии: чтение чатов и каналов, поиск по истории, отправка сообщений и файлов из Claude Code и других MCP-клиентов. - [maxstat-mcp](https://github.com/fbmdata/maxstat-mcp) — MCP-сервер для аналитики каналов (MaxStat) из ИИ-ассистентов. - [openclaw-max](https://github.com/aspalagin/openclaw-max) — плагин OpenClaw для работы с MAX из агента.  ## Интеграции и автоматизация  - [n8n-nodes-max](https://www.npmjs.com/package/n8n-nodes-max) — community-ноды n8n для MAX Bot API. - [node-red-contrib-maxbot](https://www.npmjs.com/package/node-red-contrib-maxbot) — ноды Node-RED для приёма и отправки сообщений. - [zabbix-max-webhook](https://github.com/renardein/zabbix-max-webhook) — webhook media type для Zabbix: алерты в MAX. - [GLPI-MAX](https://github.com/fsh1ne/GLPI-MAX) — плагин GLPI: уведомления о тикетах в MAX. - [ioBroker.max](https://github.com/sadam6752-tech/ioBroker.max) — адаптер ioBroker для умного дома: команды из чата, уведомления.  ## Конструкторы и no-code  - [Umbot Flow](https://flow.maxim-m.ru) — визуальный конструктор ботов поверх фреймворка umbot: собираете сценарий из блоков на холсте, проверяете в живом превью чата, экспортируете JSON и генерируете TypeScript-проект командой `npx umbot create from-flow`. Бесплатный, open-source, без регистрации; поддерживает MAX, Telegram, VK, Алису, Марусю, Viber и SmartApp. - [Mottor (LPMotor)](https://lpmotor.ru/chatbot) — коммерческий конструктор чат-ботов без кода: сценарии, CRM, оплата, рассылки; каналы включают MAX, Telegram, WhatsApp и Viber.  ## Примеры и шаблоны  - [max-bot-example](https://github.com/aleksandrvolk/max-bot-example) — полнофункциональный пример бота на Python (библиотека maxbot): команды, игры, статистика, настройки; Dockerfile и docker-compose с PostgreSQL, Redis, Prometheus, Grafana. *Пример от хостинга Bothost.* - [infobot-max](https://github.com/andryhasayan-source/infobot-max) — шаблон бота под Yandex Cloud Functions + YDB; есть варианты с бронированием и AI-ассистентом.  ## Статьи и материалы  - [MAX изменил правила доступа к платформе](https://habr.com/ru/articles/951326/) — верификация для юрлиц, ИП и самозанятых, цепочка миграций API (`botapi.max.ru` → `platform-api.max.ru` → `platform-api2.max.ru`), токен только в заголовке `Authorization`, чек-лист перед публикацией. - [Сравнение Max Bot API и Telegram Bot API метод за методом](https://vc.ru/telegram/2799410-sravnenie-max-bot-api-i-telegram-bot-api) — must have при миграции бота из Telegram. - [Max.ru Bot API: бот для обратной связи.
